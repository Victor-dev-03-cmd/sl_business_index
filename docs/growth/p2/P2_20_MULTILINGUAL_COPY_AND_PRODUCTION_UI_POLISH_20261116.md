# P2-20 — Selected-language poster copy and production UI polish

Date: 2026-11-16. Owner provided a successful Christmas 9:16 PNG showing a correct Tamil CTA but an English `CHRISTMAS SPECIAL` headline and awkward English `30% Offer for price` discount even while the UI language was தமிழ். Requested full Tamil/Sinhala/English consistency in all three copy fields, natural marketing discount wording, and no visible owner/sandbox banner on the live production route.

## Verified causes
- The existing Gemini P2-19 system prompt said to use selected language but did not strictly forbid code-switching or give useful Tamil/Sinhala/English offer few-shot examples.
- JSON validation checked allowed font family and percent truth but **did not check headline/offer/CTA script**.
- The frontend retained manually edited text across language switches, and `if(!manualHeadline)` / `if(!manualOffer)` could block a fresh translated Gemini blueprint from replacing old English copy. The default Tamil screen also started with hard-coded English `Deepavali Special` / `Contact us for details`.
- `Owner-only sandbox.` appeared in the prominent orange UI header and `Private owner QA` in the subtitle. This is inappropriate as a customer-facing product label, but it is **not** permission to remove owner-only authorization.

## Changes
1. `lib/marketing/poster-language-copy.ts`: pure Unicode-script validator for Tamil/Sinhala/English poster copy; localized initial headline and CTA, 9 seasonal headline variants, and vendor-sourced percentage badge phrasing (`30% தள்ளுபடி`, `30% වට්ටමක්`, `30% OFF`). Business name and verified contact fields are intentionally excluded from script constraints; they must stay true to the selected business.
2. `lib/marketing/poster-gemini-design-blueprint.ts`: **STRICTLY output posterCopy.headline, posterCopy.offerText and posterCopy.ctaText in the selected language**; imagePrompt stays English; concrete few-shot examples for Christmas and discounts in Tamil, Sinhala and English. Reject invented discount scope (e.g. `all services` unless the owner supplied it), dates/prices/contacts and awkward literal translations like `30% Offer for price`. Optionally uses manually reviewed `approvedOffer` as a truth source for the **numeric** discount, even if the creative art prompt does not repeat it.
3. `lib/marketing/poster-design-blueprint.ts`: server-side strict script validation for all nonempty posterCopy fields, allowlist existing font pairs, and reject unnatural English offer phrasing. Percentages are validated against the vendor's request OR separately reviewed exact offer, never invented by Gemini. Any invalid Gemini response fails safely as a review-only error; no paid Puter call is triggered.
4. `app/api/marketing/poster/puter-lab/route.ts`: pass bounded vendor-reviewed offer to the existing owner-scoped, daily-quota Gemini blueprint. No new billing, key, exposure or new endpoint.
5. `app/vendor/marketing/design/puter-lab/page.tsx`: language-specific starter headlines/CTA and sampled offers; on language switch reset automated copy and leave explicitly manual copy visible with a warning until localized; after explicit Prepare with Gemini replace stale/mismatched manual-language fields, but preserve manual content that already matches the selected language. Do not compose or download a mixed-language PNG; require correction in all modes. Changing a seasonal reference no longer silently inserts English into a Tamil/Sinhala headline.
6. Remove oversized owner-only sandbox banner and private QA subtitle from production UI; rename to **SLBI AI Poster Studio**. **Keep** explicit Puter User-Pays consent checkbox / separate no-credit sample mode, the original server-side owner-only permission check, daily Gemini quota, private image handling, trusted business info, and no auto-posting. The fact that the owner-only lab is served on Vercel production does not automatically make it available to all Pro vendors.

## QA and boundaries
- Tests: Tamil/Sinhala/English script enforcement; percentages remain grounded; phrase `30% Offer for price` rejected; translated copy samples; stale manual English fields blocked; readable local starter copy; no sandbox banner while hard access control and cost consent remain.
- Require latest GitHub PR head Next.js build / TypeScript / contract and security CI green, then merge; confirm Vercel deployment READY + live alias.
- No assistant-initiated Gemini or real Puter inference. A CI green status proves code/contract but NOT live user-generated Tamil and Sinhala output quality. Human QA on the actual browser is still needed.
- Do not silently translate user-entered company names, URLs, email, phone, verified discounts, custom brand words. Vendor retains full review of the proposed headline/offer/CTA before paid image generation.
