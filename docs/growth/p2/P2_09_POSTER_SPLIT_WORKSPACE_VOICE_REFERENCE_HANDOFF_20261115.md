## Exact owner-approved UX (important correction)
Owner requires **desktop LEFT = Prompt / Controls, RIGHT = Output image**. An earlier assistant proposed the reverse; that proposal is obsolete. This is the final approved layout.

1. **Initial first visit:** compact, centered ChatGPT-like composer (business selector, Tamil/Sinhala/English prompt, format, voice, Add reference, Generate). Avoid complex editor or preset promo/food chips.
2. **After Generate click:** transition to split screen on desktop. **Left pane** has prompt, microphone, attachments, business selector, AI-edit prompt and history. **Right pane** displays a real aspect-ratio preview canvas with animated progress, then the saved image; never text-only fake output. Avoid full-page scrolling on desktop; left panel may independently scroll. **Mobile** stacks right/output panel visually above left/controls; scrolling is acceptable.
3. **Voice:** click microphone triggers browser-native Allow permission (`getUserMedia`), records a short audio clip via MediaRecorder, POSTs only after user stops to the existing authenticated Gemini `/api/marketing/poster/transcribe`. Tamil/Sinhala/English and mixed-language transcript is placed in editable text input. **Never auto-send Generate**; user reviews transcript and clicks Generate. A microphone denial or lack of browser support shows a typed-input fallback. Existing voice endpoint has 12 owner/day server-only quota.
4. **Attach images or documents:** accept PNG/JPEG/WebP/PDF/TXT/MD, at most four files, 1.5MB each / 3.5MB combined. No DOCX parser yet; disclose that honestly. Default uploads are **reference-only**. Authenticated Pro + owner-selected business endpoint `POST /api/marketing/poster/references/analyze` sends bounded reference materials to Gemini for ephemeral style/context summary. **Never** send raw reference image pixels to Cloudflare unless the vendor explicitly checks **Use this actual image** on one image. In that opt-in case only, resize + server validate source and pass it for provider image-to-image generation. Existence of an uploaded file alone cannot imply direct use. The model may transform source pixels; perfect reproduction is not guaranteed. Reference documents are context, not authoritative listing facts. No file is made publicly accessible or stored by that endpoint.
5. **Generation progress:** show animated output frame in selected 1:1, 4:5, 9:16 or wide ratio. Percentage is labeled **estimated** (the model does not supply exact percent), bounded below 100 until real authenticated private PNG bytes have been loaded; display 100% only once truly complete. Clear error state when provider/credits/quota fails. Never claim generation complete merely because API was requested.
6. **Success:** private image on right; edit prompt on left edits same stored poster; PNG download and manually share; recent private owner-owned history. No manual X/Y/layer designer, no auto social publishing.
7. **Visual language:** polished premium neutral white + charcoal + restrained orange accent; desktop clean, mobile accessible, accessible labels, low technical burden.

## Backend implementation and boundaries
- `app/vendor/marketing/design/page.tsx`: center-to-split responsive layout, browser mic permissions → Gemini, uploads, progress estimate and private artwork preview. Business-switch clears attachments to prevent multi-business reference confusion.
- `app/api/marketing/poster/references/analyze/route.ts`: authenticated Pro + same-origin + selected owner business check; allowlisted MIME signatures, file size, daily quota; Gemini only, no Cloudflare call, no storage writes. Google may process uploaded material under Gemini account terms; UI discloses processing; do not call it strictly local/private-only.
- `lib/marketing/poster-reference-input.ts`: deny raw image source without explicit `directImageUse=true`; input binary validated, size bounded, owner-supplied image converted to 480px PNG; hashed into idempotency brief. Never read arbitrary URL.
- `app/api/marketing/poster/generate/route.ts`: request-size cap + strictly allowlisted reference context/direct source fields. Existing Pro owner check, credit reserve/claim/refund and private storage remain. Non-opt-in attachments only provide textual style summary and cannot be passed as Cloudflare `input_image_0`.
- `lib/marketing/poster-cloudflare-prompt.ts`: compact 2,048-character prioritized prompt prevents Cloudflare truncation from dropping exact vendor intent, verified selected business and relevant reference style. Generated typography may still be imperfect.
- `lib/marketing/poster-gemini-intelligence.ts`: bounded untrusted reference context never overrides authoritative selected business facts.
- `app/api/marketing/poster/capabilities/route.ts`: tells user when daily global image allowance is exhausted rather than generic Pro/connection warning.
- `tests/p2PosterStudioWorkspace.test.mjs` and updated legacy poster contracts in GitHub P2 CI. No new database migration required: reuse existing service-only `marketing_poster_voice_try_reserve` for mic and reference analysis (combined daily 12 requests/owner).
