## Deepnote vs Colab
Deepnote has hosted GPU machine options (select hardware) and paid-plan/compute availability restrictions; Colab also has GPU but dynamic quota/runtime limits. Both can train portable Python/PyTorch notebook/code. Prefer Deepnote for collaborative research if a suitable GPU is available at acceptable cost; fallback to Colab, or run tiny experiments on CPU. No assumption that Deepnote free GPU is included. Official docs: https://deepnote.com/docs/selecting-hardware ; https://deepnote.com/pricing ; https://research.google.com/colaboratory/faq.html . No claim that this assistant is connected to the user's Deepnote workspace; never imply a notebook was executed there without evidence.

## Intended architecture
Vendor Dashboard (authenticated) -> per-request tenant-scoped Context API -> Grounded multilingual Planner -> policy/capability registry -> preview + explicit vendor approval -> server-validated tool executor -> audited result. Parallel ML action-ranker reads ONLY scoped aggregates and supplies bounded ranked recommendations; cannot act itself. ONE shared versioned model weights; each vendor gets separate private context/memory, not separately trained weights by default. Train without raw sensitive client data.
