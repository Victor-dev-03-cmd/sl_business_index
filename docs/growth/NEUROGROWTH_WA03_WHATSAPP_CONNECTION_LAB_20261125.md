# WA-03 — Vendor Dashboard WhatsApp Connection Lab (UI Preview)
Date: 2026-11-25. Repository: Victor-dev-03-cmd/sl_business_index.
User request: open WhatsApp connector inside Vendor Dashboard so they can personally test it live, decide whether it belongs in Marketing Studio's Social Media Connectors or a new standalone module.

## Product decision
**Keep WhatsApp Business as a first-class card under Marketing Studio → Plugin & App Connectors → Business Messaging**, next to official social/email providers. Its multi-step setup opens a dedicated **sub-workspace** route `/vendor/marketing/whatsapp` rather than duplicating the entire Marketing Studio or creating an unrelated top-level navigation app. Also show a direct **WhatsApp Connection Lab** shortcut on the main Marketing Studio page, so even Free plan owners can review the read-only UI without getting blocked by Pro-only connector catalogue access. Real provider onboarding, subscription and publishing permissions remain separate.

## What is implemented for actual vendor visual QA
- `app/vendor/marketing/whatsapp/page.tsx`: **server component**; redirects anonymous users to login. Uses existing `createClient()` plus `auth.getUser()`, queries ONLY the current user-owned businesses via `from('businesses').select('id,name,status').eq('owner_id',user.id)`. On query/error no businesses are shown and demo actions are disabled. **Never** uses Supabase service-role, arbitrary client-supplied IDs or a WhatsApp token. No database writes.
- `app/vendor/marketing/components/WhatsAppConnectionLab.tsx`: native-looking, responsive Inter-inheriting Orange + Black + white Tailwind UI. Vendor chooses one of their own listings, inspects four connection-readiness steps, and tries a browser-only **visual demonstration** of one Tamil/English prompt → future draft/preview/individual approval/execution pipeline. Interactive select, textarea, preview and reset are local React state only; there are NO fetch requests, no number collected, no Meta credential setup, no actual WhatsApp message, no code issued, no AI inference, no poster generated and no campaign created. Clearly displays **Not connected · Preview only** at all times, including after demo.
- Existing `app/vendor/marketing/engine/(pro)/connections/page.tsx`: WhatsApp Business in `Business Messaging` now offers **Open WhatsApp setup & UI preview** linking to the sub-workspace. Every other disconnected connector remains disabled, existing Google Mail Preview unchanged. No change to `MARKETING_CONNECTORS` status `planned`.
- `app/vendor/marketing/page.tsx`: visible **WhatsApp Connection Lab** shortcut inside authenticated Marketing Studio hero; no new global navbar clutter, no premium paywall on the direct owner-safe preview route.
- `tests/wa03WhatsAppConnectionLab.test.mjs` + `.github/workflows/neurogrowth-wa03.yml`: tests route discovery, owner-scoped authentication, no Meta/provider connection claims, browser-only demo, no network/writes, and existing connector remains planned. Existing Next.js/TypeScript/Bun/postgres security CI must additionally pass.

## Official external API / privacy / launch blockers
- Meta WhatsApp Cloud API setup and Embedded Signup require official approved WABA, eligible number, provider permissions, webhook, explicit user linking, stored unique sender verification/intent replay guard and Meta policy clearance. Prototype WA-02 source is **synthetic-only**; there is NO real, persistent owner link or Meta webhook route activated.
- WhatsApp Business Solution Terms (modified 2026-03-06) restrict AI Providers exposing general-purpose AI as primary WhatsApp functionality outside listed regions; Meta determines whether SLBI's specialized vendor business-operations assistant counts as ancillary. **Sri Lankan eligibility unconfirmed; live WhatsApp operator remains disabled**. Official terms: https://www.whatsapp.com/legal/business-solution-terms/
- Approved templates outside service window and recipient opt-in/opt-out remain required; marketing/customer outreach, billing, deletes, Settings mutations, unrestricted database access are prohibited by default. No WhatsApp data used for model training.
- This is a production **UI-preview release**, NOT a connected WhatsApp integration, and no Meta API credentials, DB migration, paid resources, AI agent runtime, social/email sending or real poster creation added.
