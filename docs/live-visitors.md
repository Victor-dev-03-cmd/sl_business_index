# Live Visitors activation

Presence is an anonymous per-visible-tab count, not unique people. The old shared key caused a misleading count. No login ID, location, page or IP is sent to the presence channel. DNT/GPC are respected. Public GA4 reporting is optional; no demo data is fabricated.

Google Cloud: enable Analytics Data API; create a service account using Viewer access on the specific GA4 property. Set Vercel production server-only env vars SLBI_GA4_PROPERTY_ID (numeric, not G- measurement ID), SLBI_GA4_SERVICE_ACCOUNT_EMAIL, SLBI_GA4_PRIVATE_KEY (PEM; escaped newlines accepted). Do not use NEXT_PUBLIC_ for credentials. Prefer short-lived credentials if infrastructure supports them. Confirm GA4 collection is already configured with appropriate consent; this release does not inject third-party tracking or change consent settings. Redeploy after setting variables. Verify /api/live-visitors status ready and compare last 30 minutes in GA4; no individual pins are exposed. Locations under five hidden, others rounded down; only supported Sri Lankan city centroids are pinned. Unknown cities remain in list. World tab shows country aggregates, not a 3D globe. Report cache 60s.

## Production GA4 collection and map v2
The public tracker uses NEXT_PUBLIC_GA_MEASUREMENT_ID and explicitly requests consent, honors DNT/GPC, excludes private routes, suppresses advertising signals, and manually sends generic homepage page-view metadata. In GA4 Web stream settings turn **Enhanced measurement OFF** before enabling production collection: automatic history, search and form events must not duplicate manual measurement or collect sensitive URLs. The public map shows exact GA4 country aggregates including one, and city aggregates only for groups of five or more. Pins use Natural Earth public-domain 1:110m country polygons/label coordinates and local approximate city coordinates, not visitor GPS. The worldwide view is a pan/zoom flat map. Full view is an in-app viewport expansion, not browser Fullscreen API. No admin dashboard work in this release.

## Live area v3
Map markers now come exclusively from active Supabase Presence connections, rather than GA4 city reports. Remove static city labels/markers; one consenting active connection produces a count of one at an approximate province (Sri Lanka) or country representative point. No GPS, city, postal code, IP, auth ID or precise coordinates are transmitted to the presence channel. The network location is approximate and may be missing; no forced fallback to a city. Re-consent under slbi-ga4-consent-v2 is required to include optional area sharing. Presence state is ephemeral and the public channel includes anonymous connection keys and coarse area only. This is a tab count, not a unique-person count. GA4 remains separate for recent-user totals. No DB migration or admin changes.
